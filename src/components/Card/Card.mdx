# Card

A raised container that groups related content and actions. Cards are static, so they don't use a React Aria primitive. Interactive children, such as `Button`, bring their own behaviour.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## Usage

<Source language="tsx" code={`import { Card, Button } from "natjads";

<Card
  title="Monthly report"
  footer={<Button size="sm">Open report</Button>}
>
  Revenue grew 12% compared with last month.
</Card>`} />

## Accessibility

- Renders an `<article>`, with the title as a heading. Set `headingLevel` so headings follow the page outline (the default is `h3`).
- Avoid making the whole card clickable. Put a clear link or button inside it instead, so screen readers don't read the whole card as one control.
