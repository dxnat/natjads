# Dialog

A modal window for a focused task or a confirmation. Built on the React Aria [`DialogTrigger`, `ModalOverlay`, `Modal` and `Dialog`](https://react-spectrum.adobe.com/react-aria/Modal.html) components.

## Usage

Put the trigger button and the `Dialog` inside a `DialogTrigger`. `children` and `actions` can be functions that receive `close`.

<Source language="tsx" code={`import { Dialog, DialogTrigger, Button } from "natjads";

<DialogTrigger>
  <Button>Publish</Button>
  <Dialog
    title="Publish changes?"
    actions={({ close }) => (
      <>
        <Button variant="secondary" onPress={close}>Cancel</Button>
        <Button onPress={() => { publish(); close(); }}>Publish</Button>
      </>
    )}
  >
    Your changes will be visible to everyone in the workspace.
  </Dialog>
</DialogTrigger>`} />

## Destructive confirmation

Use `role="alertdialog"` for destructive or interrupting confirmations. Clicking outside won't close it, and you should put initial focus on the safe action (`autoFocus` on Cancel).

## Accessibility

React Aria handles:

- moving focus into the dialog, trapping it there, and returning it to the trigger on close;
- closing on <kbd>Esc</kbd>, and on a click outside when `isDismissable` is set;
- locking page scroll and hiding the rest of the page from screen readers;
- naming the dialog from its title (`slot="title"`).

Entry and exit animations use `data-entering` and `data-exiting`. With reduced motion, only a fade is used.
