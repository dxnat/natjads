# Badge

A short, non-interactive label for status or category. Badges are static text, so there's no React Aria primitive.

<Canvas of={Stories.Playground} />
<Controls of={Stories.Playground} />

## Usage

<Source language="tsx" code={`import { Badge } from "natjads";

<Badge variant="success">Active</Badge>`} />

## Variants

| Variant | Use for |
| --- | --- |
| `neutral` | Default, draft, inactive |
| `success` | Completed, active, passed |
| `warning` | Needs attention, pending |
| `danger` | Failed, error, blocked |
| `info` | New, informational |

## Accessibility

- Don't rely on colour alone. The text must say the status, such as "Failed" and not just a red badge.
- Keep labels to one or two words.
- If a badge updates live, such as a build status, wrap the region in `aria-live="polite"` so changes are announced.
