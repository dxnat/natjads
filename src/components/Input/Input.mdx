# Input

A single-line text field with a label, optional helper text and an error message. Built on the React Aria [`TextField`](https://react-spectrum.adobe.com/react-aria/TextField.html), which connects the label, description and error to the input for assistive technology.

## Usage

<Source language="tsx" code={`import { Input } from "natjads";

<Input label="Email" type="email" name="email" isRequired />

<Input
  label="Project name"
  value={name}
  onChange={setName}
  description="Shown to your team."
/>`} />

`onChange` receives the **string value**, not an event.

## Validation

Set `isInvalid` and `errorMessage` to show an error. The message replaces the helper text and is linked to the input with `aria-describedby`.

<Canvas of={Stories.Invalid} />

With native constraints such as `isRequired`, `type="email"` or `pattern`, wrapped in React Aria's `Form`, the browser's message appears on submit and focus moves to the first invalid field.

## Accessibility

- Always give a `label`, or an `aria-label` when a visible label truly isn't possible. Placeholder text is not a label.
- Errors are announced through `aria-describedby`, and the input gets `aria-invalid`.
- Hover, focus and invalid styles come from React Aria's `data-hovered`, `data-focused`, `data-focus-visible` and `data-invalid` attributes.
