# Tooltip

A short hint that appears when the trigger is hovered or focused. Built on the React Aria [`TooltipTrigger` and `Tooltip`](https://react-spectrum.adobe.com/react-aria/Tooltip.html) components.

## Accessibility

- React Aria opens the tooltip on hover (after `delay`) and on keyboard focus. It closes on <kbd>Esc</kbd>, blur or pointer leave, and links the tooltip to the trigger with `aria-describedby`.
- Tooltips don't appear on touch screens. Never put essential information or interactive content in them.
- The trigger must be focusable, such as a `Button`. A tooltip describes its trigger; it doesn't replace an `aria-label`.

## Props

Accepts all [React Aria Tooltip props](https://react-spectrum.adobe.com/react-aria/Tooltip.html#props) plus `showArrow`. `TooltipTrigger` accepts `delay`, `closeDelay`, `isOpen`, `defaultOpen`, `onOpenChange` and `isDisabled`.
