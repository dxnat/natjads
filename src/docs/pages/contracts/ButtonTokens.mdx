# Button · Token contract

The token-level contract describes **how Button is styled**: every `button/*` token from the Figma **03 Component** collection, which slot in the [component contract](?path=/docs/contracts-button-component--docs) uses it, how it resolves through the semantic and primitive tiers, and the final Light and Dark values. It also checks text contrast for each variant and state.

Generated file: `src/components/Button/button.tokens.contract.json`. Don't edit it by hand. Run `npm run contracts` after changing the component contract or the tokens.
