# Spacing

The spacing scale is based on 4px. Semantic spacing tokens describe how space is used:

- **inline**: horizontal gaps between items in a row.
- **stack**: vertical gaps between stacked items.
- **inset**: padding inside a container.
- **section**: space between page sections.
- **control**: padding and gaps inside buttons and fields.
